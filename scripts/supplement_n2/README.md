# 补充题库 · N2（全真模拟题1）

## 数据来源

《新日本语能力考试考前冲刺 N2 全真模拟题（解析版）》全真模拟题1 的扫描件（19 页），
含「语言知识・阅读」题面、听力题面与官方答案页；听力音频需扫描书页17的二维码播放。

## 收录范围

| 题包 | 大問 | 题数 |
| --- | --- | --- |
| `n2-mock1-vocab-32` | 問題1〜6（漢字読み / 表記 / 文脈規定 / 言い換え類義 / 類義表現 / 用法） | 32 |

合计 75 题，题包内序号从 1 起，`examNo` 保留卷面题号（1〜75）。

听力（問題1〜5，共 32 题）作为补充题库的「听解」板块收录，不并入绿宝书听解单元：
`src/data/supplement/listening-n2-mock1/`，整包共用书页17二维码，不参与随机练习。
其中問題3、問題4、問題5 1・2番的选项在考试中只读不放，按原书体例保留「①〜④」编号作答；
問題5 3番含两问，拆为两题收录；問題1 1番为四幅人物图，图片截自书页17。

## 答案与解析

答案以官方答案页为准；中文译文与解析由站内逐题补全，
用于练习时自查（可在应用内「反馈本题」纠错）。
読解题的 `article` 为共享文章，`Quiz` 的文章区按 `〔n〕` 标记高亮当前挖空。

## 重新生成

```bash
python scripts/supplement_n2/build_n2.py
```

脚本会写出 `src/data/supplement-n2.js`，并校验 75 题、每题 4 个选项、答案范围 1〜4。
`src/data/supplement.js` 负责把 N2 / N3 两个模块合并成补充题库入口。
