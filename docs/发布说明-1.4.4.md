# 樱花日语 v1.4.4 发布说明

发布日期：2026-11-12
版本号：1.4.4（Android versionCode 16）
（含未单独发文的 v1.4.3 内容，一并记录在下方）

## 本次变更

### 1. 桌面单词卡小组件：常见品牌适配（替代原「荣耀专属」门禁）

- 门禁由「仅 HONOR」放宽为常见安卓品牌白名单，判定依据为
  `Build.BRAND / Build.MANUFACTURER` 命中白名单，或 `Build.FINGERPRINT` 以对应品牌前缀开头：
  荣耀、华为（含 2020 年前的老荣耀）、小米 / Redmi / POCO、OPPO / 一加 / realme、
  vivo / iQOO、三星。
- 白名单实现在 `SakuraNativePlugin.isWidgetSupportedDevice()`，`getDeviceInfo` 额外返回
  `supported` 与 `brandName`；前端 `src/composables/widgetDevice.js` 取代原 `honor.js`，
  设置页标题改为「桌面小组件 · 安卓」，并显示本机品牌。
- 白名单之外的品牌：设置页不渲染入口、不同步快照；若手动添加了组件，卡片显示
  「本机暂未适配小组件」，不会出现空数据或崩溃。
- 组件 receiver 的 `android:exported` 由 `false` 改为 `true`，避免第三方桌面（小米 / OPPO / vivo 等
  自带 launcher）无法触发 `APPWIDGET_UPDATE`；组件只响应标准更新广播，不接收外部数据。
- 布局改为「角标—正文—页脚」三段约束，正文夹在角标与页脚之间并用 `autoSizeTextType` 自适应字号，
  在 2×2 到横向拉伸的不同网格下都不与页脚重叠；新增 `onAppWidgetOptionsChanged`，
  拉伸 / 换网格后即时按新尺寸重绘。

### 2. 组件刷新：不打开应用也能换词

- 组件右上角「↻」不再只是随机重掷，而是按池内顺序轮换：游标按 `appWidgetId` 存在
  `sakura_widget_state` SharedPreferences，池子走完一圈自动回到第一个。
- 快照超过 24 小时不再锁死卡片（原逻辑会隐藏 ↻ 并要求「打开应用同步」）：
  现在照常展示单词、↻ 常驻可用，只在页脚追加同步时间，例如
  `N2 · 还有 12 个待复习 · 3 天前同步`。
- 系统周期刷新（`updatePeriodMillis` 30 分钟）只重绘当前词、不推进游标，
  换词动作只由用户点 ↻ 触发。
- 只有「完全没有快照」时才提示「打开应用同步」；池为空时提示「本级暂无待练单词」。

### 3. 组件单词只取当前难度

- `widgetSync.buildSnapshot()` 取词从「全难度词库」改为「`levelStore.level` 当前难度」，
  排除熟词后按「待复习优先、其次未学」排序；快照 `pool` 上限由 30 提到 80，够多天轮换。
- 切换全局难度会立即重建快照（`watch` 增加 `level.value`），组件随之换成本级单词。
- 快照版本号升为 `v: 2`，新增 `level` / `levelLabel` / `totalCount` 字段，组件页脚据此显示难度。

## v1.4.3（补记）

### 1. N1 真题内置（2023-07 场次，66 题）

- 新增 `src/data/zhentiN1.js`：文字 6 / 語彙 19 / 文法 15 / 読解 26，共 66 题（13 个問題），
  题号 id 使用 300000 段偏移。
- 第 17 题答案册数字为笔误（印作 4，正确项原文对应 3），已按正确项原文修正；
  另有少量转换错字按通行写法校正（幼さ / 施し / しかし、僕は 等）。

### 2. 真题专区按当前难度过滤

- `/exam` 只展示与当前全局难度匹配的真题卡：选 N2 时不再出现 N3，选 N1 时只出现 N1；
  N5 / N4 显示「暂无真题」空态。
- 练习中心与首页的真题入口按当前难度统计题量并改写文案，去掉「内置 / 无需下载」类表述。

## 升级提醒

- 小组件改动集中在原生层（Provider 渲染 + 品牌判定 + 布局），Web / Windows 端只多了一套共用的
  前端代码，无可见变化。
- 已添加过组件的用户升级后无需重新添加；游标会从第 0 个词重新开始轮换。
- 数据超过 24 小时的旧快照在首次打开新版本前仍按新逻辑渲染（展示词 + 标注同步时间）。
