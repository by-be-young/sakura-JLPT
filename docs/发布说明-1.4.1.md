# 樱花日语 v1.4.1 发布说明

发布日期：2026-11-05
版本号：1.4.1（Android versionCode 13）

## 本次变更

### 1. N3 真题直接内置进应用（不再按需下载拓展包）

- v1.4.0 的「真题拓展包按需下载」方案整体废弃：不再有下载、进度、导入、文件浏览等机制，
  也无须访问 GitHub Release。
- N3 真题（2024-12 场次，70 题）已静态内嵌进应用（`src/data/zhentiN3.js`），随安装包一起分发：
  文字 12 / 語彙 21 / 文法 18 / 読解 19。
- 真题与现有练习功能直接适配：70 道真题并入 N3 题库数据流，随机练习、错题重做、收藏练习均包含真题；
  题目 key 与静态题库隔离（`N3:pack:n3-zhenti:<题号>`），作答记录、错题、收藏复用现有存储。
- 入口改为内置随练：首页「真题」mini 卡与练习中心「真题练习」卡显示「已内置 · 70 题可练」，
  `/exam` 真题专区直接「开始做题」进入 `/quiz/sequential?source=zhenti&level=N3`。
- 读解文章、挖空、排序、振假名、解析等继续复用现有 QuestionCard 渲染。

### 2. 移除拓展包机制与相关依赖

- 删除 `src/composables/useExamPacks.js`、`src/data/packQuestions.js`、`src/data/examPacks.js`。
- Electron 侧移除 `sakura-pack://` 协议、`pack:status / download / view` IPC 与 `sakuraPacks` 桥。
- Android 侧移除 `SakuraNativePlugin.downloadAsset` 原生下载方法。
- 卸载依赖：`fflate`、`@capacitor/browser`、`@capacitor/filesystem`；`cap:sync` 后
  Android 仅保留 `capacitor-android` 插件。
- 升级与自动更新链路（electron-updater + latest.yml）保持不变。

## 升级提醒

v1.4.0 及更早的桌面端用户启动应用后，`设置 → 检查更新` 会发现 v1.4.1 并自动更新（electron-updater）；
Android 用户需手动安装 `sakura-japanese-1.4.1-debug.apk`（覆盖安装即可，数据保留）。
v1.4.0 及更早版本内「真题拓展包」相关下载入口与已下载的包数据不再使用，可忽略。
