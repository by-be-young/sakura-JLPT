# 樱花日语 v1.5.0 发布说明

发布日期：2026-11-26
版本号：1.5.0（Android versionCode 21）

## 本次变更：N3 补充题库扩充至 1000 题

### 题库构成

- N3 补充题库由 7 个题包组成，共 **1000 题**，全部来自公开网页题源，不再包含站内原创题。
- 163 道原有外部精选题保留。
- 新增 Challenge JLPT 816 题：
  - 文字・語彙 325 题
  - 文法 241 题
  - 汉字读解 250 题
- 新增資格ブートキャンプ补充题 21 题，覆盖汉字读音、表记、文脉规定、言い換え、用法与文法。
- 所有题目保留原始 `sourceId`，便于回查原网页。

### 中文译文与解析

- 816 道 Challenge 题已全部补齐句子中文译文；1000 题当前不存在空译文。
- 解析优先使用源站中文翻译；部分题目仍保留日文原解析，后续可继续分批补齐。
- 答题后展示「译文 → 解析」，答错时停留当前题，答对时按原流程进入下一题。

### 页面与移动端

- 补充题库改为按「語彙 / 文法」分组，保留题包总数、完成进度与「第 N 套」标识。
- 語彙 746 题、文法 254 题；汉字与混合题包归入語彙分组。
- 补充题库页与语汇/文法/汉字答题页在 390×844 移动端复检通过，无横向溢出；选项、答题卡、汉字下划线正常。

## 同期变更：N2 补充题库

- 新增 N2 全真模拟题 1（语言知识・阅读）75 题。
- 新增 N2 模拟题 2（文字・語彙 / 文法 / 読解）75 题，按类别并入模拟题 1 的三个题包，合并后共 150 题。
- 新增两套 N2 聴解补充题组，按問題 1〜5 收录，整包共用书页二维码音频，不参与随机练习。

## 视觉与交互

- 首页、练习中心、补充题库及背词/文法/读解/听解等页面统一为同一套视觉语言，沿用樱花粉与圆角卡片体系。
- 移动端继续压缩顶部工具条与底部 Dock，统一使用 760 / 640 两档断点。
- 更新提示、错误边界、答题卡与题库筛选等交互细节同步收口。

## 校验

- `python scripts/supplement_n3/validate_data.py`：1000 题、7 个题包、答案范围与题包数量全部通过，缺失译文 0。
- `npx vite build`：通过。
- 移动端 390×844：补充题库页、三类答题页与全站主要路由无横向溢出。
