# 樱花日语 v1.4.6 发布说明

发布日期：2026-11-15
版本号：1.4.6（Android versionCode 18）

## 本次变更

### 1. N5 真题内置（2021-12 场次，43 题）

- 新增 `src/data/zhentiN5.js`，把 N5 2021-12 场次整卷结构化进应用：
  文字 12 / 語彙 9 / 文法 17 / 読解 5，共 43 题（文字・語彙 問題1-4 + 文法・読解 問題1-6）。
  题号统一重排为 1-43（文字語彙 1-21、文法読解 22-43），id 使用 500000 段偏移
  （`ZHENTI_ID_OFFSET.N5`），不与 N1/N2/N3/N4 及静态题库冲突。
- 素材情况：`N5\2021-12\试卷.pdf` 为纯扫描件（17 页，p1-p8 为言語知識・読解，p9 起为聴解），
  逐页渲染后人工转录题干与四个选项；答案来自该场次公开答案册，两处独立来源互证：
  - 宁波爱心日语学校「2021年12月N5答案」网页（纯文本答案键）
  - unojapano.com「[FULL] JLPT N5 – 12/2021 Full Questionnaires and Answers」（Yuuki Bùi）
  - 两来源在 もじ・ごい 問題1-4 与 ぶんぽう・どっかい 問題1-3 前段逐项一致。
- 逐题校验：43 题题号连续、每题 4 个选项且互不重复、答案在 1-4 之间、与答案键逐项比对 0 错点；
  4 道並べ替え题按卷面 ★ 实际位置反推选项号，全部与答案键一致（含第 31 题 ★ 位于第 2 个空位的情形）。

### 2. 真题专区按难度过滤

- 选 N5 时只显示 N5 卡（2021-12 · 共 43 题 · 文字 12 / 語彙 9 / 文法 17 / 読解 5），
  N1 / N2 / N3 / N4 各自只显示本级；空态文案更新为「N1 / N2 / N3 / N4 / N5」。
- 首页与练习中心的真题入口按当前难度统计，N5 难度下显示「N5 真题 · 整卷随练」与 43 题。
- 真题卡片文案保持简短：仅「场次 · 共 N 题」「覆盖文字 / 語彙 / 文法 / 読解」与题型分布，无来源类表述。
