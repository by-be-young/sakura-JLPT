# 樱花日语 v1.4.5 发布说明

发布日期：2026-11-15
版本号：1.4.5（Android versionCode 17）

## 本次变更

### 1. N4 真题内置（2021-12 场次，56 题）

- 新增 `src/data/zhentiN4.js`，把 N4 2021-12 场次整卷结构化进应用，随安装包分发：
  文字 11 / 語彙 16 / 文法 21 / 読解 8，共 56 题。
  题号 id 使用 400000 段偏移（`ZHENTI_ID_OFFSET.N4`），不与 N1/N2/N3 及静态题库冲突。
- 素材情况：该场次试卷为纯扫描件（无文本层，20 页，其中后 8 页为聴解），
  逐页渲染后人工转录题干与四个选项；答案取自同场次 `答案.pdf`（もじ・ごい 1-28、
  ぶんぽう・どっかい 1-29）。
- **题量说明**：原卷共 57 题，素材第 2 页缺失原卷第 12 题（問題2 第 5 题），
  因此本套收录 56 题，题号统一重排为 1-56；文法問題3 文章内挖空相应编号为〔45〕～〔48〕。
- 逐题校验：每题 4 个选项、选项互不重复、答案在 1-4 之间、与答案册 57 项答案键逐项比对全部一致。
  其中文法問題1 第 6 题（父は朝ごはんの前に…）答案册正文误抄为「もうすぐ」，答案键为②，
  按答案键与语义取②「かならず」。

### 2. 真题专区按难度过滤（沿用 v1.4.3 逻辑）

- 选 N4 时只显示 N4 卡，选 N1/N2/N3 各自只显示本级；N5 仍显示空态提示，文案已更新为
  「可通过顶部难度选择切换到 N1 / N2 / N3 / N4」。
- 首页、练习中心的真题入口按当前难度统计，N4 难度下显示「N4 真题 · 整卷随练」与 56 题。

### 3. N5 真题暂缓的原因

- 素材目录里 N5 三个场次（2021-12 / 2022-12 / 2024-07）均只有试卷、没有答案册；
  其中 `N5\2022-12\试卷.pdf` 实为答案册（无配套试卷），`N5\2021-12`、`N5\2024-07` 是原始扫描卷。
- 缺答案键无法保证判分正确，因此本轮不出 N5 题；等有配套「试卷 + 答案」的场次再按同一标准补入。
