# 用户故事与验收标准

- 角色缩写：**游客**（未登录学习者）、**学员**（已登录学习者）、**管理员**、**发布者**（运维）
- 优先级：**M**（Must，本期必做）、**S**（Should）、**C**（Could）
- 验收标准统一用 Given / When / Then；每条故事对应 SRS 的功能编号（见 [SRS.md](./SRS.md)）

---

## 故事地图（按旅程）

| 阶段 | Epic | 用户目标 |
| --- | --- | --- |
| 进入 | E1 入门与导航 | 3 秒内知道"我现在在学哪一级、今天该做什么" |
| 巩固 | E2 刷题 / E3 模拟 | 把真题刷完、看清对错、记住错题 |
| 输入 | E4 背词 / E5 文法 / E6 读解 / E7 听解 | 用手机把词、句型、文章、听力逐块消化 |
| 复盘 | E8 数据与账号 | 知道自己的真实水平，换设备不断档 |
| 运营 | E9 维护与发布 | 修内容、看反馈、稳定发版 |

## E1 入门与导航

### US-01 切换备考等级（M · FR-01.3）
**作为**游客，**我希望**一键在 N5–N1 之间切换，**以便**只在当前目标等级的内容里学习。

- Given 我在任意页面，When 我点击等级徽标并选择 N3，Then 顶栏与所有列表立即切换为 N3 数据，且刷新后仍为 N3。
- Given 我切到没有题库的等级（如 N5），When 我进入练习中心，Then 题库/模拟卡置灰并提示"待补充"，不出现空列表或报错。

### US-02 手机上的导航（M · FR-01.2）
**作为**学员，**我希望**手机上用底部 Dock 换页、顶部只留必要控制，**以便**拇指可达且不挤占内容。

- Given 视口 ≤760px，When 我打开任意页面，Then 一级入口链接在顶栏隐藏、底部 Dock 显示 5 项且当前项高亮。
- Given 视口 ≥761px，When 我打开同一页面，Then 顶部导航显示完整文字链接、Dock 不显示。

### US-03 振假名帮助读汉字（S · FR-01.5）
**作为**初学者，**我希望**开合振假名，**以便**不认识汉字时也能读，做题时又不被答案提示。

- Given 我在答题且尚未提交，When 我尝试点击振假名开关，Then 提示"提交后可切换"且状态不变。
- Given 我已提交答案，When 我点击开关，Then 正文与解析立即在 ruby / 纯文本之间切换。

### US-04 深色模式（S · FR-01.4）
**作为**夜间学习者，**我希望**切到深色或跟随系统，**以便**长时间阅读不刺眼。

- Given 主题为"跟随系统"，When 系统切换深色，Then 页面自动变深、`theme-color` 同步更新。
- Given 我手动选"深色"，When 系统切回浅色，Then 仍保持深色（手动优先）。

## E2 刷题

### US-05 顺序刷题并看解析（M · FR-04.1/4.3）
**作为**学员，**我希望**按题号顺序刷题并即时看到解析，**以便**边做边学。

- Given 我在 `#/quiz/sequential`，When 我点选项，Then 正确项变绿、错误项变红、解析展开，按钮锁定不可二次作答。
- Given 我已完成第 12 题，When 我点"下一题"，Then 进入第 13 题且进度条前进。

### US-06 用答题卡跳题（S · FR-04.2）
**作为**学员，**我希望**用答题卡看到答过哪些题并跳转，**以便**回头检查。

- Given 顺序/单元/模拟模式，When 我展开答题卡，Then 每题显示三态颜色（未答/对/错），点击即跳转。

### US-07 收藏与错题沉淀（M · FR-04.4/4.5）
**作为**学员，**我希望**答错自动进错题本、答对自动移出，并能收藏重点题，**以便**二轮只练该练的。

- Given 我答错第 7 题，When 我打开"我的"，Then 错题本出现该题并显示"最近答错"时间。
- Given 我在错题本重做该题并答对，Then 该题从错题本消失。

### US-08 随机练习（C · FR-04.1）
**作为**学员，**我希望**随机抽题并可"全随机洗牌"，**以便**避免记住题号顺序。

- Given 我开启"全随机"，When 我重新进入随机模式，Then 顺序与上次不同且设置被记住。

### US-09 按单元练（S · FR-04.1）
**作为**学员，**我希望**只练某一单元，**以便**配合教材进度。

- Given 我选择"单元模式"并选第 3 单元，Then 题目全部来自 `unit === 3`，题号升序。

## E3 模拟测试

### US-10 按回次全真模拟（S · FR-05）
**作为**学员，**我希望**按回次抽整卷并计分，**以便**检验真实水平。

- Given 我在练习中心选第 2 回，When 我交卷，Then 结果页给出得分，且"已完成套数/均分"更新。
- Given 该回尚未上线，When 我点击，Then 提示占位文案且不进入空试卷。

## E4 背词

### US-11 每日新学（M · FR-06.1）
**作为**学员，**我希望**每天按目标学新词，**以便**有节奏地推进词库。

- Given 今日目标为 20，When 我完成一轮新学，Then 今日背词计数增加、目标环前进、连续打卡保持。

### US-12 多种题型轮换（M · FR-06.2）
**作为**学员，**我希望**同一个词练"假名→汉字、汉字→假名、词义互选、例句挖空、近反义"，**以便**真正掌握而非只会认。

- Given 某个词有汉字、有释义、有含该词的例句，When 我学到它，Then 依次出现 5 种可用题型，全部答对后该词标记为"背完"。
- Given 某个词没有近义词配置，Then 不生成近义题（不出现无正确项的题）。

### US-13 复习生疏词（S · FR-06.5）
**作为**学员，**我希望**错过 2 次或 2 天没复习的词自动回到复习池，**以便**不遗忘。

- Given 某词 `wrongCount = 2`，When 我进入复习，Then 该词出现在复习列表。
- Given 我在复习里自评"没问题"，Then 该词错误计数清零、`lastReviewAt` 更新，不再立即出现。

### US-14 熟词与笔记（C · FR-06.6/6.7）
**作为**学员，**我希望**把已会的词标为熟词、给难词写笔记，**以便**缩小学习面并留下记忆线索。

- Given 我把某词标为熟词，Then 它不再出现在新学与复习，但计入"已学"。
- Given 我给某词写笔记，When 我在另一台设备登录，Then 笔记同步出现。

## E5 文法

### US-15 分页精读（M · FR-07.2）
**作为**学员，**我希望**一次只看一个文法点并翻页，**以便**专注。

- Given 我在分页模式，When 我按 `D` 或点右箭头，Then 翻到下一个点，页码与进度同步；首/尾页对应按钮禁用。

### US-16 顺序速览（S · FR-07.2）
**作为**学员，**我希望**连续滚动整章，**以便**快速回顾。

- Given 我切到顺序模式，Then 该级别记住该模式，刷新后仍为顺序模式。

### US-17 目录定位与标记（S · FR-07.3/7.4）
**作为**学员，**我希望**从目录跳到任意点并把难点打 ★，**以便**二次复习直击重点。

- Given 我打开目录，Then 按单元分组列出全部点，当前点高亮，★ 点带标记。
- Given 我点某个点，Then 抽屉关闭且滚动到该点（分页模式则翻到该页）。

### US-18 手机上的单行工具条（M · FR-15.2/15.3）
**作为**手机用户，**我希望**阅读时上方只占一条细栏，**以便**一屏多读几行文法。

- Given 视口 390×844 且打开 `#/study/n3`，Then 工具条高度 ≤50px、内容单行不换行，正文起始位置 ≤120px。
- Given 视口 320×568，Then 工具条不溢出、无横向滚动，正文高度 ≥320px。

### US-19 清空标记但保留进度（C · FR-07.8）
**作为**学员，**我希望**在文法概览页把两类清理分开，**以便**只重置我不想要的部分。

- Given 我在 `#/study` 点"清空标记"，Then ★ 全部清空，已学进度与最近位置仍在。
- Given 我点"清空学习进度"，Then 已读/位置/阅读模式重置，★ 标记保留。

## E6 读解

### US-20 文章 + 逐题作答（M · FR-08）
**作为**学员，**我希望**左看文章右做题（手机上下排布），**以便**边读边验证理解。

- Given 我打开第 1 篇，When 我答完全部小题，Then 出现"全文翻译与难句分析"解锁区；未答完时该区显示锁定提示。

### US-21 手机上读解工具条不换行（M · FR-15.4）
**作为**手机用户，**我希望**顶栏只显示返回与标题，**以便**文章正文占满屏幕。

- Given 视口 ≤760px 打开 `#/reading/1`，Then 顶栏单行、高度 ≤50px，标签与百分比不占第二行。
- Given 同时打开底部答题条，Then 该条单行且不遮挡正文最后一行。

## E7 听解

### US-22 单元三板块切换（M · FR-09.2）
**作为**学员，**我希望**在词汇/题目/知识之间切换，**以便**按教材顺序学一个单元。

- Given 我打开第 1 单元，Then 三个 Tab 均可切换，词汇按组列出、题目可展开答案、知识卡成对展示。

### US-23 扫码听教材音频（S · FR-09.3）
**作为**学员，**我希望**点二维码卡片放大后扫码，**以便**用教材原音练习。

- Given 我点音频卡，Then 弹出放大二维码并提示扫码；关闭后回到原位置。

## E8 数据与账号

### US-24 今日进度与打卡（M · FR-02.1/2.2）
**作为**学员，**我希望**首页就看到今天完成多少、连续多少天，**以便**维持动力。

- Given 我今天答了 12 题、背了 8 词，When 我回到首页，Then 环与芯片显示 12/20、8/20，连续天数正确（今天没活动时从昨天起算）。

### US-25 看清自己的水平（M · FR-10.2）
**作为**学员，**我希望**看到正确率、按级进度、错题与收藏，**以便**决定下一步。

- Given 我一题都没答，Then 正确率显示为 0 而**不是** NaN（分母为 0 时按 0 处理）。

### US-26 独立清除与备份（S · FR-11.3/11.4）
**作为**学员，**我希望**只清某一类数据、并能导出/导入 JSON 备份，**以便**换机不丢进度。

- Given 我导出备份后清空背词进度，When 我导入备份，Then 已学/熟词/笔记全部恢复；每日打卡独立保留。

### US-27 跨设备同步（M · FR-12）
**作为**学员，**我希望**登录后两台设备进度一致，**以便**手机和电脑接着学。

- Given 设备 A 已答 40 题、设备 B 已答 10 题，When 设备 B 登录，Then 合并后为并集（不丢数据），且不出现白屏。

### US-28 云端脏数据兜底（M · FR-12.4）
**作为**学员，**我希望**即使云端数据被写坏，页面也能正常显示。

- Given 云端 `wrong` 被写成对象 `{}`，When 我登录合并，Then `wrong` 被修复为数组，错题本正常渲染。

### US-29 未配置云端也能用（M · FR-12.5）
**作为**游客，**我希望**不登录也能完整学习。

- Given 构建时未填 anon key，When 我点登录，Then 提示"未配置云端"，本地学习功能全部可用。

### US-30 提交反馈（S · FR-13.1）
**作为**学员，**我希望**在做题页反馈该题问题、在设置页提建议，**以便**内容被修正。

- Given 我在第 5 题点 💬 提交，Then `feedbacks` 新增一条带 `question_id` 的记录，默认 `status = open`。
- Given 我在设置页"意见反馈"提交一般反馈，Then 记录 `type = general`，未登录也可提交。

### US-31 管理员处理反馈（S · FR-13.3）
**作为**管理员，**我希望**看到所有反馈并标记已处理。

- Given 我登录且不在 `admins` 表，When 我访问 `#/admin/feedback`，Then 显示无权限提示，不拉取数据。
- Given 我在表内，Then 可按 open/resolved 筛选并切换状态。

### US-32 版本更新（C · FR-14）
**作为**用户，**我希望**知道有新版本并按平台更新。

- Given Electron 检测到新版本，Then 显示版本号与下载进度，完成后可立即安装。
- Given 离线或未配置仓库，Then 静默不提示。

## E9 维护与发布

### US-33 内容扩充不改代码逻辑（M）
**作为**发布者，**我希望**新增题库/词条只需替换数据文件，**以便**低风险迭代。

- Given 我在 `src/data` 追加合规结构的题目，Then 新题自动出现在题库、答题卡、统计中，无需改视图代码。

### US-34 构建安全闸（M · NFR-05）
**作为**发布者，**我希望**误把高权限密钥打进包时构建直接失败。

- Given 我把 anon key 换成 `service_role`，When 我执行 `npm run build`，Then 构建中断并报错，不产出安装包。

### US-35 断点与高度预算不被破坏（S · FR-15.8）
**作为**前端维护者，**我希望**改动移动端样式后桌面不受影响。

- Given 我在 ≤760px 媒体查询内新增样式，When 我以 1180×900 打开同一页面，Then 布局与改动前逐像素一致（工具条含文字按钮、Dock 不显示）。
