# 樱花日语 v1.5.1 发布说明

发布日期：2026-11-26
版本号：1.5.1（Android versionCode 22）

## 本版变更：N3 补充题库结构统一

- N3 补充题库由原来的 7 个来源/小题型题包合并为 2 个语言知识题包：
  - `n3-vocab`：文字・語彙 **736 题**
  - `n3-grammar`：文法 **264 题**
  - 合计 **1000 题**
- 题包内不再区分原题源或小题型；汉字、语汇、混合题中的语汇部分并入 `n3-vocab`，文法题并入 `n3-grammar`。
- 补充题库页现在与 N2 一致：每个语言知识域只显示一张题包卡，不再显示「第 N 套」、来源名或子题型筛选。
- 答题页题型标签统一为「語彙 / 文法」。
- 合并时保留原题包的答题 key；升级后已有 N3 补充题库进度会继续计入新题包。
- 1000 道题、原有补充题库入口和答题统计逻辑保持不变。

## 验证

- `python scripts/supplement_n3/validate_data.py`：1000 题、2 个题包、答案范围与题包数量全部通过，缺失译文 0。
- `npx vite build`：通过。
- 390×844 移动端：补充题库页仅两张题包卡，无「第 N 套」、来源名或小题型 chips，无横向溢出。

## 升级说明

- Windows 安装包为 NSIS 安装版，可直接覆盖安装。
- Android 调试包与上一版签名一致时可覆盖安装；如提示签名冲突，先卸载旧版再安装。
- 本版只调整 N3 补充题库的题包组织方式，不影响其他题库、学习记录与账号数据。
