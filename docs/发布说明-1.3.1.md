# 樱花日语 v1.3.1 发布说明

发布日期：2026-11-03
版本号：1.3.1（Android versionCode 10）

## 本次修复

修复移动端（Android / PWA）「检查更新」始终提示“当前已是最新版本”的问题。

根因：`index.html` 从未引用 `public/update-config.js`，页面里 `window.UPDATE_CONFIG` 恒为空，
`useUpdater` 取不到 GitHub 仓库地址后直接判定为“无更新”。桌面端走 `electron-updater`，不受影响。

具体改动：

1. `index.html` 在应用模块脚本之前引入 `./update-config.js`，保证 `window.UPDATE_CONFIG` 在
   `useUpdater` 初始化前就位。
2. `useUpdater.init(force)` 支持强制重查：设置页手动点「检查更新」会真正重新请求，而不是复用
   启动时那次结果。
3. 检查失败不再伪装成“已是最新”：未配置更新源、HTTP 非 2xx、网络异常、读不到本地版本分别进入
   `error` 状态，并在界面上显示具体原因。
4. `Settings.vue` 的更新描述与手动检查提示同步区分「已是最新 / 发现新版本 / 检查失败」。

## 升级提醒

已安装 1.2.3 或 1.3.0 的设备，**包内是旧逻辑，无法自己发现 1.3.1**，需要手动安装一次本次 APK。
装好 1.3.1 之后，后续版本即可正常收到更新提示。
