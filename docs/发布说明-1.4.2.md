# 樱花日语 v1.4.2 发布说明

发布日期：2026-11-09
版本号：1.4.2（Android versionCode 14）

## 本次变更

### 1. N2 真题内置（2021-12 场次，71 题）

- 新增 `src/data/zhentiN2.js`，把 N2 2021-12 场次整卷结构化内嵌进应用，随安装包分发：
  文字 10 / 語彙 20 / 文法 21 / 読解 20，共 71 题（含問題14 的第 70、71 题）。
- 数据来源为该场次试卷 PDF 的文本层，答案解析取自同期答案册；逐题校验：每题 4 个选项、
  答案键与答案册一致、読解題全部带文章、完型填空文章内挖空〔48〕～〔51〕可定位高亮。
- 与 N3 真题共用一套数据结构（`packId` / `session` / `source` 字段同构），
  题号 id 使用独立基数（N2 为 200000 段、N3 为 100000 段），两包不冲突、也不与静态题库冲突。
- 随机练习、错题重做、收藏练习均已包含 N2 真题；作答记录、错题、收藏沿用现有存储。

### 2. 真题专区改为 N2 / N3 双卡

- `/exam` 由单卡改为两卡：分别显示级别、场次、题量与题型分布，
  跳转 `/quiz/sequential?source=zhenti&level=<L>&pack=<packId>`（带 `pack` 参数，避免两包混题）。
- 首页「真题」mini 卡与练习中心文案统一为「N2 / N3 真题 · 已内置随练」。

### 3. 移动端练习页改为左右滑动切题

- 屏幕宽度 ≤760px 时彻底隐藏左右翻页按钮，改为左滑下一题、右滑上一题：
  横向位移阈值 56px，且需明显大于纵向位移（防与页面滚动冲突），另有 350ms 防误触窗口，
  避免滑动与点选选项互相干扰；页面底部保留滑动提示。
- 桌面端保持不变：左右箭头、A / D 快捷键仍然可用。

### 4. 修复真题文章挖空高亮错位

- 文章内挖空高亮原先按 `id` 判断当前题，真题 id 带级别偏移导致永不命中；
  改为按卷面题号（`examNo`）判断，N2 / N3 文章挖空均能正确高亮当前题。
