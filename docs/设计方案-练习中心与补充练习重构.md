# 设计方案 · 练习中心与补充练习重构

> 状态：待确认（本文只做设计，不含代码改动）
> 范围：练习入口 IA、补充练习分域、随机配比、听解题组归属
> 关联：`src/views/Learn.vue`、`src/views/Supplement.vue`、`src/views/Quiz.vue`、`src/data/{questions,supplement,listening}.js`
> 视觉原型：`docs/mockups/practice-center.html`（截图 `docs/mockups/shots/A.png`、`B.png`）

---

## 1. 现状问题（为什么要改）

| # | 问题 | 表现 |
| --- | --- | --- |
| P1 | 补充题库没有「能力域」这一层 | 一个页面平铺 10 个题包（N3 7 个 + N2 3 个），语汇/文法/阅读混排，用户只能靠题包名猜内容 |
| P2 | 听解没有归属 | 绿宝书听解是独立板块；N2 全真模拟题1 听力被塞成 `Unit16`，和教材单元并列，来源、体例都不一致 |
| P3 | 随机练习不可控 | 只有「完全随机」一个开关，无法只练阅读、无法调比重，也无法在补充题库里随机 |
| P4 | 同一件事有两套入口 | 专项训练里同时有「阅读训练 / 听力单元 / 补充题库」，三者与主线题库的关系看不出来 |
| P5 | 统计口径割裂 | 补充题库独立统计，但页面上没有按域的完成度，用户不知道「我语法练到哪了」 |

结论：缺的不是功能，而是**两层结构**——「题源（主线 / 补充 / 真题）」×「能力域（語彙・文法・読解・聴解）」。把这两层显式化，听解的归属和随机配比都能自然落地。

---

## 2. 设计目标

1. 任何题目都能回答三个问题：**来自哪本书、属于哪个能力域、练到什么程度**。
2. 听解回到「题组」本位：一套听力 = 一个题组（含若干大問），不再伪装成教材单元。
3. 随机练习从「一个开关」升级为「可配比的组卷器」，主线与补充共用同一套交互。
4. 不新增页面层级深度：练习 →（题源）→（域）→ 题包/题组 → 作答，最多 4 层。

**不做**：不做跨题源混卷（红蓝宝书 + 外部题源混在一张卷里）；不做听解与阅读混排随机（音频无法与静默答题同流）；不改动既有答题记录 key。

---

## 3. 方案对比与选择

| 方案 | 做法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| A 单层平铺 | 练习页直接列 4 个域，域内再分来源 | 层级最浅 | 题源品牌（红蓝宝书）被稀释，主线/补充统计混在一起 |
| B 题源 × 域（推荐） | 主线、补充、真题三块并列；补充内部再分 4 域；随机配比在「题源」内生效 | 来源清晰、统计可分别累计、随机范围可控 | 需要一次页面改版 |
| C 单一题库混源 | 只有一个题库，用域 + 来源双筛选 | 概念最少 | 红蓝宝书/补充的正确率会混算，错题来源难追溯 |

**推荐 B。** 理由：现有产品已经把「红蓝宝书」当作主线和品牌，补充题库的定位是「外部题源、独立统计」——这个区分是有价值的，不该在 UI 上抹平；但两者应该共用同一套「域」语言和同一个随机配比组件。

### 5.2 补充练习页（/supplement）

**结构**：页头 → 域切换条（吸顶）→ 域分区 → 题包/题组卡。

```
补充练习  N2                           [← 练习]
外部题源 · 4 个能力域 · 75 题 + 1 个听力题组

┌ 全部 75 ┬ 文字・語彙 32 ┬ 文法 22 ┬ 読解 21 ┬ 聴解 32 ┐   ← 吸顶，带计数
│                                                          │
│ 文字・語彙   32 题 · 完成 12 (38%)        [顺序练习 →]    │
│ ┌───────────────────────────────────────────────────┐    │
│ │ 全真模拟题1 · 問題1〜6                 32 题  ▓▓░░  │    │
│ │ 漢字読み / 表記 / 文脈規定 / 言い換え / 用法        │    │
│ │ 正确率 71% · 错题 5                                  │    │
│ └───────────────────────────────────────────────────┘    │
│                                                          │
│ 文法   22 题 · 完成 0 (0%)                               │
│ ┌ 全真模拟题1 · 問題7〜9  22 题 ┐ ┌ 文法形式 12 题 … ┐   │
│                                                          │
│ 読解   21 题                                             │
│ 聴解   1 个题组 · 32 题                                  │
│ ┌───────────────────────────────────────────────────┐    │
│ │ [QR] 全真模拟题1 聴解   6 大問 · 32 题              │    │
│ │ 書页17 二维码 · 官方答案 · 已完成 0/32              │    │
│ └───────────────────────────────────────────────────┘    │
└──────────────────────────────────────────────────────────┘
```

设计要点：

- **域切换条**是筛选，不是新路由：切换只过滤列表，保持滚动位置感；`全部` 用分组标题展示，单域 tab 用平铺。
- 域色一域一色（見 7.1），题包卡左侧 3px 色条，扫视即知类别。
- 每个域标题右侧常驻一个「随机练本域」次级入口，避免用户为了随机再回上一页。
- 听力卡与题包卡**不同形**：左侧二维码缩略 + 右侧「大問/题数/音频」信息，明确它不是普通题包。
- 完成度按 `answered / total`，与现有 `supplementStatsOfLevel` 同口径；错题数取 `store.wrong` 中本域的交集。

### 5.3 随机配比面板（新增核心交互）

入口：主线「随机抽题」卡、补充页「随机练习」按钮、Quiz 随机模式顶部的「调整配比」。

形态：桌面端右侧抽屉（宽 420，页面内容不遮死）；移动端底部全屏 sheet（85vh，可下拉关闭）。**不新开页面**，避免打断「准备开始练习」的心流。

```
┌ 随机练习 · 配比                    ✕ ┐
│ 范围  [红蓝宝书 ▾]  N2 · 801 题      │
│                                      │
│ 能力域            权重      预计      │
│ ◉ 文字・語彙    ▾2 档  40%   8 题     │
│ ◉ 文法          ▾2 档  40%   8 题     │
│ ◉ 読解          ▾1 档  20%   4 题     │
│ ○ 聴解          题组制，单独练 →      │
│                                      │
│ 题量  ( 10 ) ( 20 ) ( 30 ) ( 全部 )   │
│ 预设  均衡 · 弱项优先 · 上次配比       │
│                                      │
│ ☑ 优先出未做过的题                    │
│ 本次：20 题 · 語彙 8 / 文法 8 / 読解 4 │
│ [        开始练习        ]           │
└──────────────────────────────────────┘
```

交互规则：

1. **档位而非百分比滑杆**：0–4 档，归一化后实时显示百分比与预计题数。理由：移动端滑杆精度差，且 3 个域必须凑 100% 会让用户反复微调；档位表达「相对比重」更符合直觉（2:2:1）。
2. 只开一个域时，该域权重自动锁定为 100%，其余行置灰但保留可见（让用户知道还有哪些域）。
3. 域内可用题不足时，预计题数按可用量截断，并在行尾提示「可用 12 题」，不静默失败。
4. 总量超池子时按总量截断，底部提示「本级共 801 题，本次取 200」。
5. 「弱项优先」预设 = 按各域历史正确率反向配权（正确率低的档位高），一键可用，不做复杂推荐算法。
6. 配比按「范围」分别记忆：`sakura_random_mix:bank`、`sakura_random_mix:supplement`；换范围不串味。
7. 面板底部始终显示结果摘要（题量 + 各域题数），点击开始前就能预期这张卷子长什么样。

**算法**（前端纯函数，`buildWeightedList(pool, weights, total, opts)`）：

```
1. 按域切池；剔除权重为 0 的域；池内 unseen 优先、seen 其次，各自乱序
2. 最大余数法分配题数：count_i = total * w_i / Σw，余数按小数部分降序补
3. 每个域至少 1 题（若 total ≥ 启用域数且该域有题）
4. 各域按分配数切片，域内乱序
5. 交错合并：按 w_i 的比例做轮转（每轮从权重最高的域取 1 题），避免连续 3 题同域
6. 不足则回补其他域；超出则按 total 截断
```

### 5.4 主线题库同款

- 「顺序答题」增加域筛选 chips（全部 / 語彙 / 文法 / 読解），起始题定位到该域第一道未做题。
- 「随机抽题」直接进配比面板（范围=红蓝宝书），默认上次配比；无历史则均衡。
- 单元练习不受影响。
- 主线题库的 `読解` 只有 20 题（N2），配比行显示「可用 20 题」以免误解。

### 5.5 听力题组页（/supplement/listening/:id）

从 ListeningUnit 的题目区抽象出共用渲染，但**入口和面包屑归补充练习**：

```
补充练习 › 聴解 › 全真模拟题1 聴解

[QR 音频卡]  模1 · 全篇     第 1/6 大题 · 問題1 課題理解
─────────────────────────────────────────────
1 番  [图片选项] ① ② ③ ④
2 番  ケーキ / 何も買わない / ネクタイ / 猫の置物
...
```

- 顶部 6 个大問做 tab（問題1〜5，問題5 拆 1・2 番与 3 番），也可沿用左右翻页卡片，二选一，推荐 tab + 进度点。
- 二维码卡常驻吸顶，随时可扫；桌面端提示「用手机扫码」。
- 每题作答后展开答案与解析；无解析的题只给官方答案。
- 无选项的题（問題3/4/5-1・2）统一话术：「选项在录音中读出，按编号作答」，避免出现空选项区。
- 题组完成后回写 `finished` 标记，补充练习页的聴解卡显示进度。

## 6. 数据与代码层设计

### 6.1 能力域归一

不手改生成物，在聚合层派生：

```js
// supplement.js / questions.js 共用
const DOMAIN_BY_TYPE = { 文字: 'vocab', 語彙: 'vocab', 文法: 'grammar', 読解: 'reading', 聴解: 'listening' }
q.domain = q.domain || DOMAIN_BY_TYPE[q.type] || 'other'
```

`domain` 只做分组与筛选，不参与答题比对，改动零风险。

### 6.2 题包扩展字段

```js
pack.domain = 'vocab' | 'grammar' | 'reading' | 'listening'
pack.scope = 'bank' | 'supplement'
pack.source // 已有 provider 可直接复用
```

### 6.3 听力题组注册表

```
src/data/supplement/listening/
├── index.js        // groups: [{id, level, domain:'listening', title, subtitle, source, qrKey, sections}]
└── mock1/          // 由 unit16 迁入的 questions.js（sections 数组直接复用）
```

`qrKey` 取代页码字符串，`qrImg()` 的扩展映射改为按 key 查表，不再依赖 level 页码表。

### 6.4 路由

| 路由 | 说明 |
| --- | --- |
| `/supplement?domain=vocab` | 域筛选可分享，默认 `all` |
| `/supplement/listening/:id` | 听力题组页（新增） |

`/listening/16` 直接下线即可（无外部链接），如需兜底可在路由加 redirect 到 `/supplement?domain=listening`。

## 7. 视觉规范

### 7.1 域色板（沿用站内 token）

| 域 | 主色 | 底色 | 图标语义 |
| --- | --- | --- | --- |
| 文字・語彙 | `--amber #d99a3d` | `--amber-soft` | 字 |
| 文法 | `--iris #7c6cf0` | `--iris-soft` | 文 |
| 読解 | 陶土 `#d98b45` | `#fdf0e4` | 読 |
| 聴解 | 玉绿 `#3fae83` | `#e8f6f0` | 聴 |

规则：一屏内最多出现 4 个域色；域色只用于**识别**，不用于强调按钮（按钮仍用 sakura 渐变），避免主色泛滥。

### 7.2 版式

- 桌面：内容宽 1000；域卡 4 列（≥900）/ 2 列（760–900）/ 1 列（<620）。
- 域切换条：胶囊 segmented，高 40，选中态白底 + 域色文字 + 细描边；计数用 `tabular-nums`。
- 题包卡：圆角 18，1px 描边，卡内左 3px 域色条；hover 位移 3px、描边换域色 20% 透明度。
- 配比面板：圆角 20（抽屉右侧无圆角），标题 serif 20，行高 44，档位用 5 段刻度点而非滑杆。
- 字号：标题 serif 22–40；正文 12–14；辅助 9.5–11，letter-spacing 1–2（沿用现有 journal 语言）。

### 7.3 动效

- 域切换：内容 180ms 淡入 + 6px 上移；切换条指示块 220ms `ease-out-expo` 滑动。
- 面板：桌面 260ms 右侧滑入 + 遮罩渐显；移动 320ms 底部上推。
- 档位调整：预期题数数字 120ms 数字滚动感（仅透明度/位移，不做真实计数动画）。
- 禁止：卡片 3D 翻转、长时间骨架屏。

### 7.4 无障碍与移动端

- 域切换用 `role="tablist"` + 键盘左右切换；档位用可聚焦的分段按钮，`aria-valuetext="2 档，40%"`。
- 触控目标 ≥ 40×40；底部 sheet 内按钮避开安全区。
- 听力 QR 卡提供文字兜底「教材第 17 页」与「用手机扫码」。

## 8. 边界与异常

| 场景 | 处理 |
| --- | --- |
| N3 补充无読解 | 読解 tab 置灰 + 「本级暂无」；配比行禁用并说明 |
| 某域题量 < 请求分配 | 行尾显示可用量，剩余配额回补其他域 |
| 只勾一个域 | 其余行禁用但可见，权重锁定 100% |
| 全部域权重为 0 | 开始按钮禁用，提示「至少选一个能力域」 |
| 总题量 > 池子 | 截断并提示实际题数 |
| 无错题 / 无收藏 | 入口保留但禁用，副文案「还没有错题」 |
| 听力题组未完成 | 卡显示 `已答 n/32`，不做百分比进度环（题组非连续作答） |
| 旧链接 `/listening/16` | 路由重定向到 `/supplement?domain=listening` |

## 9. 分阶段实施

| 阶段 | 内容 | 预估 | 交付物 |
| --- | --- | --- | --- |
| P0 | domain 派生、pack 扩展、听力题组迁出 Unit16、路由兜底 | 0.5 天 | 数据层 + `supplement/listening/` |
| P1 | 补充练习页改版（域 tab、分组、听力卡、空态） | 1 天 | `Supplement.vue` + 3 个组件 |
| P2 | 配比面板 + `useRandomMix` + Quiz 随机模式接入（主线 & 补充） | 1 天 | `RandomMixPanel.vue` + composable |
| P3 | 听力题组页（抽出渲染组件、tab、QR 吸顶） | 0.5 天 | `/supplement/listening/:id` |
| P4 | 文案、弱项预设、移动端走查、构建校验（不发布新版本） | 0.5 天 | 走查记录 |

依赖顺序：P0 → P1/P2 可并行 → P3 → P4。

**验收标准**

1. 补充练习页可一眼分出 4 个域，每域显示题量与完成度；听力显示为题组而非题包。
2. 绿宝书听解列表恢复 15 个单元，N2 全真模拟听力只在补充 › 聴解 出现。
3. 主线与补充的随机入口都能调 3 个域的档位，看到的预计题数与实际出题数一致（误差 0）。
4. 配比刷新页面后保留；主线与补充互不影响。
5. 任何域题量不足、全零权重、超总量都不会出现空白页或死按钮。
6. 现有答题记录、错题、收藏的 key 与统计不受影响（回归：N2 801 题、N3 补充 1000 题、补充 N2 75 题）。

## 10. 待你确认的 3 个决策（括号内为建议）

1. **聴解是否进随机配比？** 建议不进入统一随机，保持「题组单独练」；若你希望听力也能被随机抽到，需要另做「题组随机」模式（一次抽 1 个大問，带音频卡），成本 +0.5 天。
2. **权重交互形态？** 建议 0–4 档位 + 实时百分比；备选是百分比滑杆（更直观但要凑 100%，移动端难调）。
3. **默认题量？** 建议 20 题（10 适合碎片时间，30 接近一次小测）；可在设置里记住上次选择。

另：你说的「文法 / 语法」我按同一个能力域处理（`文法 = 语法`），拆成两行会造成重复计数；若你本意是「語彙 / 文法」，那正好对应本方案的「文字・語彙」「文法」两行。
