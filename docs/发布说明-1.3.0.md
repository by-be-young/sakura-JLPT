# 樱花日语 v1.3.0 发布说明

发布日：2026-10-30 · Tag：`v1.3.0` · 上一版本：`v1.2.3`

## 本次更新

### 移动端排版收敛

- 顶部导航：高度 59px → **47px**，品牌名收小，振假名 / 主题 / 设置改为 30px 纯图标按钮（振假名只保留「あ」）。
- 文法阅读页工具条：两行 118px → **单行 48px**，返回与目录改为图标，只保留「N3 · 第 N/M 点」+ 分页/顺序切换；隐去「分页阅读」标签、重复点数与 ★ 徽标。
- 文法纸面：高度由 `100dvh-330` 提升到 `100dvh-190`，正文起始位置 207px → **115px**（390×844 下纸面 514px → **654px**，首屏即可看到接续 + 说明 + 例文）。
- 底部翻页条：66px → **46px**，圆形箭头 + 页码 + 3px 细进度。
- 底部 Dock：60px → **54px**。
- 读解页顶栏与底部答题条：各压到 46px，标签与百分比不再另起一行。
- 听解单元页头：≤640px 隐去 kicker 与题量/知识芯片，保留返回 + 标题 + 主题。
- 320 / 360 / 390 三档宽度均单行不溢出；1180×900 桌面布局零变化。

### 移动端不再显示键盘快捷键提示

触屏没有物理键盘，移动端（≤760px）移除全部快捷键提示；桌面（≥761px）全部保留：

- 文法目录抽屉底部「点击目录项跳转 · **Esc 关闭**」→ 只留「点击目录项跳转」。
- 听解单元「**A** 上一组 **D** 下一组」键位说明条 → 隐藏（按钮文案本身已表达方向）。
- 背词复习页头「**快捷键 1 / 2 / 3**」与按钮角标「**按 1 / 按 2 / 按 3**」→ 隐藏。
- 背词学习页头「**Enter 翻面 · A / D 切换 · F 熟词 · N 笔记**」→ 只留「点击卡片翻面」。
- 背词学习主按钮「下一个 → **(D)**」→ 只留「下一个 →」。

## 升级说明

- Windows：安装包会覆盖安装，用户数据（localStorage）保留；旧版 1.2.3 启动后会自动检测到 1.3.0 并提示更新。
- Android：直接安装新 APK 覆盖即可（同一签名 / 同一 applicationId `com.sakura.japanese`）。
- 无破坏性数据变更：localStorage 键与 Supabase 表结构均未改动，无需迁移。
