| 项目 | 内容 |

---

## 1. 背景与目标

自学者在备考 JLPT 时缺一套"词—文法—读—听—刷题"闭环工具，常见痛点是：题库分散、进度不可见、跨设备断档、离线不可用、移动端阅读被界面挤占。

本产品目标：

1. **一套数据、四个训练维度**：背词（红宝书）、文法（蓝宝书）、读解（橙宝书）、听解（绿宝书）+ 真题题库与模拟，进度统一可见。
2. **离线优先**：全部内容与学习记录本地可用，网络仅用于账号同步、反馈与更新。
3. **多端一体**：同一份源码产出桌面安装包、APK 与可添加到主屏的 PWA。
4. **移动端优先的阅读体验**：小屏上"内容 > 控件"，任何常驻工具条不得占据超过单行高度。

---

## 2. 术语

| 术语 | 含义 |
| --- | --- |
| 等级 / Level | N5、N4、N3、N2、N1 五档；全局单选，贯穿所有模块 |
| 题库 / 题库练习 | 按 `level` 抽题的真题练习，2000 题（N2/N3 各 1000） |
| 模拟 / 回次 | 按级别第 1–5 回抽取整卷，计分并留存成绩 |
| 文法点 / Point | 文法最小教学单元（接续、说明、例文、注意事项） |
| 标记 / ★ | 用户在文法点上打的收藏标记，用于目录快速定位 |
| 熟词 | 背词中已掌握、不再进入新学与复习的词 |
| 生疏 | `wrongCount ≥ 2` 或距上次复习 ≥ 2 天的已学词 |
| 云同步 | 登录后把本地题库状态与背词状态与 Supabase 合并 |
| 振假名 | 汉字上方标注平假名（ruby） |

## 3. 用户与角色

| 角色 | 说明 | 权限 |
| --- | --- | --- |
| 游客（未登录） | 默认态，数据仅存本机 | 全部学习功能；可提交反馈（可留联系方式）；不能云同步 |
| 登录用户 | 邮箱注册/登录 | 游客权限 + 跨设备云同步 + 查看自己提交的反馈 |
| 管理员 | 在 `admins` 表登记的用户 | 登录用户权限 + 查看全部反馈并标记已处理/恢复待处理 |
| 运维者 | 发布者本人 | 建表、配置密钥、发版（不通过应用内界面操作） |

角色判定：`useAuth` 登录后查询 `admins` 表，命中即 `isAdmin`；表不存在或 RLS 未配时容错为 `false`。

## 4. 运行环境与约束

- 技术栈：Vue 3 + Vite 5 + vue-router 4（hash 路由），无 UI 框架；Electron 44、Capacitor 8。
- 目标浏览器/容器：Chromium 内核（Electron）、Android WebView、iOS Safari 15+。
- 布局断点：480 / 640 / 760 / 820 / 900；必须适配 320px 宽与 `env(safe-area-inset-*)`。
- 云端可选：未配置 `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` 时进入纯本地模式，相关入口降级提示而非报错。
- 密钥纪律：客户端产物只允许 anon public key，构建脚本会解码校验并阻断。

## 8. 界面需求（移动端高度预算）

以 390×844（iPhone 12/13/14 逻辑分辨率）为基准，文法阅读页（分页模式）实测：

| 区域 | 优化前 | 优化后 | 变化 |
| --- | --- | --- | --- |
| 顶部导航 | 59px | 47px | −12 |
| 文法工具条 | 118px | 48px | −70 |
| 正文/纸面起始位置 | 207px | 115px | −92 |
| 纸面高度 | 514px | 654px | **+140（+27%）** |
| 底部翻页条 | 66px | 46px | −20 |
| 底部 Dock | 60px | 54px | −6 |

规则：

1. ≤760px 每页最多一条常驻工具条；工具条内元素一律不换行。
2. 文本标签能省则省（"分页阅读""第 N / M 点"中的量词、★ 计数徽标在窄屏隐藏）。
3. 文字型入口（返回、目录）在窄屏只留图标，但必须保留 `title` 与 `aria-label`。
4. 正文高度用 `calc(100dvh - Npx)` 计算，N 随工具条高度调整；320×568 下正文不得低于 320px。
5. 桌面（≥761px）布局零变化。

## 10. 约束与假设

- 假设用户已安装现代浏览器/系统版本；IE 与老旧 WebView 不支持。
- iOS 无法原生编译，仅以 PWA 形式交付（需用户手动"添加到主屏幕"）。
- 更新依赖 GitHub Releases；未发布前不提示更新。
- 内容数据来自既有教材整理，**不允许手改** `src/data/grammar.js` 等生成文件。
- 本次变更打包为 **1.3.0**（Windows NSIS 安装包 + Android debug APK + Web 静态包）；上传 GitHub Release 需运维者本人提供 `GH_TOKEN`。
