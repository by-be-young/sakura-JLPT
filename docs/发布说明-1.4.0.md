# 樱花日语 v1.4.0 发布说明

发布日期：2026-11-05
版本号：1.4.0（Android versionCode 12）

## 本次新增

### 1. N3 真题拓展包（按需下载，不随安装包分发）

- 首页「练习」区新增「真题」入口，进入 `/exam` 页面浏览拓展包清单。
- 仅在用户主动点击「下载」时从 GitHub Release 拉取；桌面端自动下载解压并显示进度（下载/解压百分比），
  Web / PWA / Android 端因 GitHub 资产 CDN 无 CORS 头，采用「打开下载页手动下载 + 导入 zip」两步安装。
- 包内容：2022-07 ~ 2024-12 共 6 场 N3 真题（试卷 / 答案 / 听力原文，不含音频），
  附带 2024-12 场次 70 题结构化题库（`questions.json`：文字 12 / 語彙 21 / 文法 18 / 読解 19）。
- Electron 侧新增 `sakura-pack://` 只读协议与 `pack:status / download / view` IPC，
  安装目录 `<userData>/packs/<packId>/<version>/`；PDF 用内置阅读器在新窗口打开。

### 2. 真题与现有练习功能适配

- 安装拓展包后，70 道真题自动并入 N3 题库数据流：随机练习、错题重做、收藏练习均会包含真题，
  题目 key 与静态题库隔离（`N3:pack:n3-zhenti:1`），作答记录、错题、收藏全部复用现有存储。
- 「真题专项」入口直达 `/quiz/sequential?source=zhenti&pack=n3-zhenti&level=N3`，
  可跨当前等级做题（读解文章、挖空、排序题、振假名、解析均复用现有 QuestionCard 渲染）。

## 修订记录（2026-11-05 同日）

- **移动端下载修复①**：Android WebView 中 `window.open` 会被静默拦截（Capacitor 未实现 `onCreateWindow`），
  下载无反应。已改为安装 `@capacitor/browser` 插件，Android/iOS 端点击「下载」用系统浏览器 / Custom Tab
  打开 GitHub 下载页；并新增「↻ 重新打开下载页」兜底按钮。
- **练习页入口**：练习中心（`/learn`）新增「真题练习」卡片（全宽，橙色渐变，显示包状态：按需下载 / 下载中 /
  待导入 / 已安装 N 题可练），点击进入 `/exam`。
- **移动端下载修复②（应用内原生下载 + 进度条）**：浏览器跳转仍被用户反馈为「没有反应 / 没有进度」。
  现已改为 Android 应用内直接下载：本地插件 `SakuraNativePlugin.downloadAsset` 用 HttpURLConnection
  流式下载到应用缓存，逐块回调进度（每 64KB），前端显示「下载中」百分比进度条；下载完成后自动解压、
  写入 IndexedDB 并注入题库，与手动导入流程一致。为此新增 `@capacitor/filesystem` 依赖，
  下载页兜底（`↻ 重新打开下载页`）保留在安装失败时可用。Web / PWA 因 GitHub CDN 无 CORS 头，
  仍为「手动下载 + 导入 zip」（导入同样显示进度并自动注入）。
- 同步重建 Android APK（含原生下载插件，46,470,875 字节）并更新到本 Release。
