# 樱花日语 v1.3.2 发布说明

发布日期：2026-11-05
版本号：1.3.2（Android versionCode 11）

## 本次新增

### 1. 荣耀 400 桌面单词卡小组件（荣耀专属，P0）

- 荣耀设备门禁：仅 `Build.BRAND/MANUFACTURER == HONOR`（或指纹 `HONOR/` 前缀）的设备，
  设置页才会出现「桌面小组件 · 荣耀专属」分组；老荣耀（HUAWEI 品牌字段）与其它品牌不可见。
- 组件行为：2×2 单词卡随机展示一个**待复习（优先）或未学**的单词（词形 + 假名 + 释义），
  右上角 ↻ 可原地换词；点击主区域经白名单深链直达 `/words/review`（有待复习词）或 `/words/learn`。
- 选词口径与背词模块一致：错≥2 次或距上次复习≥2 天判为待复习，排除熟词，池子不够回落未学词
  （快照 pool ≤ 30 条）。
- 数据同步：应用内即时写入 `widget_snapshot.json`，学习/打卡变化自动重建，回到前台补同步；
  组件 30 分钟系统轮询兜底；超过 24 小时未更新显示「打开应用同步」。
- 发布策略：P0 主包内置 + 荣耀门禁（快速验证）；P1 再拆同签名双 APK「按需下载」插件。

### 2. 移动端样式优化（4 项）

1. 系统任务栏：Capacitor 端启动即隐藏状态栏（可下拉临时唤出）；无法隐藏的 Web/PWA 端通过
   safe-area 内边距规避刘海/挖孔遮挡。
2. 修复首页滚到底时「听解」卡片被底部悬浮导航遮挡（根因：≤640px 的容器 padding 简写覆盖了
   ≤760px 的底部留白规则）。
3. 底部导航选中项：文字不再显示，图标在 52px 高度内真正垂直居中（同时修复了选中底衬盖住文字的层级问题）。
4. 答题页移动端适配：箭头/卡片/选项/解析/文章全部紧凑化，参考文法页（GrammarReader）做法，
   为底部悬浮导航让位。
